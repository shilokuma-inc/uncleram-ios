## 何を作るか

**Uncle RAM**（アンクル・ラム）は、端末の本物のメモリを「献上」する押し引きゲームです。iPhone / iPad / Mac で遊べます。

- **遊び方:** 長押ししている間だけメモリを確保し、離すと「納品」になります。隠れた「回収ライン」を越えると、そのラウンドの献上分はすべて失われます。
- **世界観:** 架空の巨大 AI 企業「アロケート社」と、そのマロック会長がメモリを集めて回ります。社是は「全人類の RAM を、ひとつの AI に。」です。
- **元ネタ:** 2026 年のメモリ高騰と、「個人の PC がメモリを抱えるのは非効率」というミームです。実在の人物・企業・ロゴは一切出しません。
- **安全:** 安全ラインで必ず止めるので、OS による強制終了（jetsam）は起こしません。

## ユーザーが確認した既定値（2026-11-12）

仕様を詰める中で既定値として決め、ユーザーが確認した点です。実装で迷ったときの根拠にしてください。

- 早期回収は 1 割のラウンド。カロック・ラボには入れない（アロケート社 30〜50%、リアロック 35〜50%）
- はったりは 15% のラウンドで、偽物は「気配」だけ。1 秒で引っ込み、会長がにやりと笑う
- 警告（3 段階目）は「もう手遅れかも」の合図。ここで離しても半分ほどは回収される
- ヒント精度アップを最後まで上げると強すぎるが、定期便はランキング外なので許す（価格と下げ幅は試作で調整）
- 定期便のラウンドの倍率は ×1.0 / 1.2 / 1.5 / 2.0 / 3.0。回収されると未確定のスコアとクレジットを失う
- 回収されても称号の累計（換算献上量）は減らない
- 途中でアプリを閉じたら「降りた」扱い
- デイリーは、その日のうち（世界標準時 0 時まで）はラインの位置を見せない
- 降りる・続けるの主ボタン（赤）は「続ける」
- 英語の用語: Cash out / Continue / Unbanked / Sign → Approach → Warning（既存の Donate / Deliver / Collect / Budget に合わせる）

## 数値の初期値（試作で調整する）

| 項目 | 値 |
| --- | --- |
| 枠（iOS） | ラウンド開始時の `os_proc_available_memory()` |
| 枠（Mac） | `host_statistics64` の free + inactive + purgeable の 60%。搭載メモリの 50% と 32GB を上限にする |
| 安全ライン | 確保のたびに「献上量＋確保量 ≤ 枠 × 85%」と「今の残量 − 確保量 ≥ max(枠 × 15%, 200MB)」の両方を確かめる。満たさなければその量で納品（回収ではない）。枠が 600MB 未満なら遊べないことを案内する |
| 献上の速さ | 枠の 30% までは 10%/秒。30% から先は 5%/秒で始め、1 秒ごとに 10% 速くなり、上限は 9%/秒（55% まで約 7 秒、80% まで約 10 秒）。回収ラインには左右されない。確保は 0.1 秒ごと、16MB 単位 |
| 回収ライン | カロック・ラボ 50〜60%（早期回収なし）、アロケート社 55〜80%、リアロック・データセンター 60〜75%（ラウンド中に ±5% 動く）。アロケート社とリアロックは 1 割のラウンドが「早期回収」（30〜50% / 35〜50%）。どれも「安全ライン − 枠の 5%」を越えない |
| ニアミス倍率 | 納品が成功したときだけ。離した瞬間の回収ラインとの差が枠の 3% 以内なら ×3、10% 以内なら ×1.5 |
| スコア | 献上量（MB）× ニアミス倍率 × 取引先の倍率 × ラウンドの倍率（後の 2 つは定期便だけ。ラウンドの倍率は ×1.0 / 1.2 / 1.5 / 2.0 / 3.0） |
| 腕前スコア | 回収ラインへの到達率（納品量 ÷ 回収ライン × 100）× ニアミス倍率。最大 300 pt。回収されたら 0 |
| ヒント | 回収ラインの手前、枠の 15%（±4）/ 8%（±2.5）/ 2%（±2）で 3 段階（気配＝会長の表情、接近＝飛行船の音、警告＝画面のノイズ。振動も）。ヒント精度アップは 1・2 段階の揺らぎを 1 段階ごとに 25% 減らす。15% のラウンドで偽の「気配」（はったり）を 1 秒だけ出す |
| 取引先の倍率 | ×1.0 / ×1.5 / ×2.0（定期便だけ） |
| クレジット | 定期便で降りて確定した換算献上量 100MB ごとに 1 cr。回収されると未確定分は消える（換算献上量の累計は納品したラウンドの分を数える） |
| 強化 | ヒント精度アップ 1 段階 400 cr（3 段階）、長押し減速 300 cr、回収保険 600 cr（使い切り） |
| 回収保険 | 1 プレイ最大 1 回。支援パックの保険とは重ねない。発動したら回収ライン直前の量で納品、ニアミス倍率なし |
| 称号 | 定期便の換算献上量の累計 50GB で優良提供者、250GB で模範的な提供者、1TB で名誉株主。特別な称号は「満額寸前の人」（ニアミス ×3 を通算 10 回）、「空き容量の守り人」（回収されずに 50 ラウンド連続） |
| リアロックの解放 | 換算献上量の累計 20GB |
| ランキングのクラス | iPhone / iPad: 8GB 以下 / 12GB / 16GB 以上。Mac: 16GB 以下 / 24–32GB / 48GB 以上（physicalMemory を正式な容量に丸める） |
| デイリーの種 | SHA-256("UncleRAM-daily-v1-" + 世界標準時の YYYYMMDD) の先頭 8 バイト → 自前の SplitMix64。乱数を使う順番は早期回収かどうか → 回収ライン → ヒントの揺らぎ → はったり → 振動の揺らぎで固定 |

## ラウンドの状態（要点）

- **待機 → 献上中:** ボタンを押すと献上中になります。
- **献上中 →:**
  - 離す → 納品の判定
  - 回収ラインを越える → 回収
  - 安全ラインに当たる → 納品
  - メモリ警告 → 監査（納品扱い）
- **納品・回収・監査:** **先に全メモリを解放してから**演出を始めます。献上中は新しい画像や音を読み込みません。
- **離したとみなす:** scenePhase が inactive になったとき、タッチがキャンセルされたとき、Mac でウィンドウが前面でなくなったとき。
- **無効にする:** バックグラウンドへの移行と、発熱が serious 以上になったとき。スコア 0、クレジットなしです。デイリーは無効でも挑戦済みにします。
- **ウィンドウ:** 1 つだけにします（Mac は Window、iPad は UIApplicationSupportsMultipleScenes = NO）。

## 構成の提案

ここは提案です。実装するセッションの判断で変えてかまいません。

| 部品 | 役割 |
| --- | --- |
| `MemoryProbe`（プロトコル） | 枠と残量を返す。iOS は `os_proc_available_memory()`、Mac は `host_statistics64`。テスト用の偽物を差し込める |
| `Allocator` | 16MB 単位の確保と書き込み、全解放。安全ラインの判定はここで必ず通す（ほかから確保できないようにする） |
| `RoundEngine` | 状態遷移・速さ・回収ライン・ヒント・判定。時刻と乱数と `MemoryProbe` を外から渡し、単体テストで動かせるようにする |
| `DailySeed` / `SplitMix64` | デイリーの種と乱数。端末が違っても同じ値になることを単体テストで固定する |
| `Progress` | 換算献上量・クレジット・称号・強化。iCloud のキー値ストアとの同期と、端末ごとのキーの合算 |
| `PriceTable` | prices.json の取得・キャッシュ・内蔵の値。Storefront（なければ Locale.region）で円かドルかを決める |
| `Store` | StoreKit 2。`Transaction.updates` の監視、復元、返金、承認待ち |
| `Leaderboards` | Game Center。14 本のランキング、実績、送り直し |
| `Share` | ImageRenderer で明細書を描く。AVAssetWriter で記録からリプレイ動画を作る |
| `Feedback` | 音（AVAudioSession は .ambient）と振動（Core Haptics） |

## 段取り（マイルストーン）

1. **準備:**
   - template-app-ios から `shilokuma-inc/uncleram-ios` を作り、`~/Desktop/ios/uncleram-ios` に clone する（名前は確定。公開・非公開はユーザーに確認する）
   - `scripts/rename.sh UncleRAM` を実行し、`Configs/Project.xcconfig` に Bundle ID と iOS 18 を設定する
   - 同じターゲットに macOS 15 を足す
   - CI に Mac 用の Archive・Export・Upload を足す
2. **試作（合格条件）:** 速達便 1 ラウンドを、iPhone と Mac で実際にメモリを確保して動かします。裏で音楽を流し、iPad は Split View にした状態で、次をすべて満たすことが条件です。
   - 100 ラウンド続けて強制終了が 0 回
   - 60fps を保つ
   - メモリの解放が 200ms 以内
   - Mac でスワップが増えない
   - App Sandbox を有効にしても `host_statistics64` の値が取れる

   対象は、枠の小さい iPhone、標準的な iPhone、メモリの大きい iPad、Mac の 4 種類です。あわせて、ページごとに少しだけ乱数を書く方式でも使用量に計上されるか（圧縮されないか）も測ります。
3. **速達便が遊べる版:** 速達便・デイリー・共有・ランキングを入れ、TestFlight の公開テストを始めます。
   - 説明なしで分かる UI（練習ラウンド、場面ごとの吹き出し、ゲージの濃淡、結果でのライン表示）もこの版に入れます。初めての 5 人に説明なしで遊んでもらい、最初の 1 回で納品できるかを確かめます
   - 早期回収・ヒントの出方・はったり・速さの数値は [tools/sim.py](tools/sim.py) で試算した値です。触ってみて調整したら、sim.py で期待値と回収される割合を確かめ直します
4. **全部入りの版:** 定期便、取引先、強化、称号、課金、iCloud 同期、BGM、9 言語を入れます。
5. **仕上げと申請:** 次を済ませて申請します。
   - スクリーンショット（UI テストで 9 言語 × 3 端末を撮影）
   - 審査メモ（SPEC.md「審査メモ（App Review Notes）の文案」）
   - 価格の再確認
   - プライバシーマニフェスト
   - 暗号化の申告（ITSAppUsesNonExemptEncryption = NO）
   - Universal Links（Associated Domains と apple-app-site-association）

遅れそうなときは、次の順に後回しにします。社内報フィード → 代替アイコン → 社章スキン集 → リアロック・データセンター。

## まだ確かめていないこと

- **Mac の値の取得:** App Sandbox を有効にした状態で `host_statistics64` の値が取れるか（Sandbox なしでは確認済み）。

- **価格の出典:** 2025 年 3 月の日本の価格は記事の値（公式ストアで確認したものではない）。価格は公開の直前にもう一度確かめる。

- **プライバシー:** Game Center を使うときのプライバシー表記と、サイトのアクセスログの扱い。
- **法務:** 電気通信事業法についての判断は専門家に確認したものではない（自由入力を持たない構成なので届出は不要という前提）。
